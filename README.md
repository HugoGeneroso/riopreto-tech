# Rio Preto Tech — Site institucional

Site da agência riopreto.tech — sites para negócios locais de São José do Rio Preto/SP.

- Single-page HTML/CSS autocontido (sem build, sem dependências)
- Deploy: Railway (estático) → apontar domínio riopreto.tech

## Deploy no Railway
1. New Project → Deploy from GitHub repo → este repo
2. Railway detecta como estático (index.html na raiz)
3. Settings → Networking → Generate Domain → depois Custom Domain: riopreto.tech
